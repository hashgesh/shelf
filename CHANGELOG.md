## [0.1.0] - 2026-10-31

- Config layer with file, env and flag precedence
- Artifactory AQL client with httptest coverage
- Conan model, path parsing and profile matching
- List and show commands with filters and JSON output
- TUI base layout with package list and binary table
- TUI filters, search, detail window and clipboard copy
- Matrix view in CLI and TUI

### Fixed

- Clearer TUI selection and detail scroll hint
- Stop AQL paging when a page brings no new items
- Retry AQL without sort on Artifactory OSS

### Documentation

- README user guide with screenshots

### Changed

- Project skeleton with Makefile, build.ps1 and lint config
- GitHub Actions for tests, lint and tagged releases
- Cover unsorted paging; document OSS paging limits
- Ship release binaries as .tar.gz and .zip archives
